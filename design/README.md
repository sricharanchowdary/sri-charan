# Design Artifacts

This folder contains the lightweight design artifacts created before the final
implementation pass.

- `wireframes.svg` shows home, project case study, and contact in desktop and
  mobile arrangements.
- `theme-board.svg` shows the light and dark theme palette side by side.

The implementation intentionally stays close to these artifacts: simple
navigation, a strong home introduction, case-study cards, readable long-form
content, and a contact form with visible success and error states.
